# data/voynich_botany — G10++ Voynich plant pages × CCAT

**Synthetic botanical controls only.** No Beinecke IIIF or POWO images are
bundled — those are optional and were not fetched (see `BLOCKED_IIIF` / `NEVER_ATTEMPTED`
in the verdict if applicable).

Contents:
- Synthetic plant-page images generated by `tools/scripts/voynich_botany_probe.py`
  at runtime (not committed). The generator creates stylised botanical drawings
  (stem + leaves + root + flower) for Known-Answer positive controls.
- Null controls: random noise, scrambled coordinates, random shapes.

No real Voynich manuscript page images are included. This is a **shape-structure
only** analysis — not a botanical identification or herbal-decipherment effort.

Stance: **structure ≠ herbal ID / decipherment.**
