# VASCO Candidate Catalog — Vanishing Sources in POSS I Red Images

## Source

Extracted from the SVO (Spanish Virtual Observatory) archive of vanishing
objects in POSS I red images, as described in:

> Solano, E., Villarroel, B., & Rodrigo, C. (2022). *Discovering vanishing
> objects in POSS I red images using the Virtual Observatory.* Monthly Notices
> of the Royal Astronomical Society, 515(1), 1380–1391.
> doi:10.1093/mnras/stac1552

## Contents

| File | Description |
|------|-------------|
| `vasco_candidates.csv` | 5,399 candidate vanishing sources detected in POSS I red images. Columns: RA (deg), DEC (deg), dis_arcsec (distance to nearest modern match), img_possi (POSS I image ID), img_ps (Pan-STARRS image ID). |
