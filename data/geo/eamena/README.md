## Subset rationale

Full EAMENA corpus is ~338k records. These published Zenodo subsets provide tractable
first passes for collinearity FPR calibration:

- **Wadi Naqqat** (14 sites ~500 m across) — first-pass sanity check.
- **Sistan part 1** (1,626 point features) — main calibration dataset.

Structure ≠ message. This data is used for null-model calibration, not for any claim about leys, ancient grids, or extraterrestrial intervention.
