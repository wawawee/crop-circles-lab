# Indus West — G9++ Barbara West negative control data

## Source

| Dataset | Status | Source |
|---------|--------|--------|
| **Barbara West-style tables** | `NEVER_ATTEMPTED` | Wells 2015 *The Archaeology and Epigraphy of Indus Writing*, Appendix II: Positional Analysis of Indus Signs. Book under copyright; no public machine-readable dump at time of analysis. |
| **Tamil inscription corpus** | `NEVER_ATTEMPTED` | Mahadevan 2003 *Tamil-Brahmi Inscriptions*. No public sign-sequence dump found in machine-readable format. |
| **Telugu inscription corpus** | `NEVER_ATTEMPTED` | Early Telugu epigraphic corpora not in public machine-readable format. |
| **Fixture** | `synthetic` | Generated deterministically from known Mohenjo-daro sign distribution (mayig corpus). |

## Stance

Structure != meaning. This data is **fixture-only** for pipeline validation.
No decipherment, no language-family claims.
