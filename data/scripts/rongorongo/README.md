# Rongorongo corpus — Spaelti XML edition

**Source:** Spaelti, P. *Rongorongo corpus* (XML edition). GitHub: https://github.com/phspaelti/RR-corpus

**License:** Open-access research corpus (Spaelti). See http://kohaumotu.org/Rongorongo/ for terms.

**Contents:**
- `A.xml`–`F.xml` — Tablet transcriptions in Spaelti XML (Barthel glyph codes + SVG tracings)
- Loaded via `tools/scripts/rongorongo_probe.py` → `symbolseq`

**Tablets:**
| File | Code | Name | Sides | Total glyphs |
|------|------|------|-------|-------------|
| A.xml | A | Tahua | Aa, Ab | ~1,846 |
| B.xml | B | Aruku Kurenga | Br, Bv | ~1,302 |
| C.xml | C | Mamari | Ca, Cb | ~1,025 |
| D.xml | D | Échancrée | Da, Db | ~316 |
| E.xml | E | Keiti | Er, Ev | ~895 |
| F.xml | F | Chauvet fragment | Fa, Fb | ~76 |

**Glyph encoding:** Barthel 3-digit codes (e.g. `001`, `430!`, `095bjt`).  
Special values: `_` = gap/blank, `000!` = damaged/unreadable frame.

**Citation:**
> Barthel, T. S. (1958). *Grundlagen zur Entzifferung der Osterinselschrift*. Hamburg: Cram, de Gruyter.
> Spaelti, P. *Rongorongo* [online]. http://kohaumotu.org/Rongorongo/
